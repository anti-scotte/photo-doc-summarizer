# docs/

这里放项目文档用图，目前约定一张：

| 文件 | 用途 |
|---|---|
| `screenshot.png` | README 顶部的主界面截图 |

## 怎么补这张图

1. 启动项目（双击 `run.bat`）
2. 传一份样例文件，等五栏结果出来
3. 截取整个浏览器窗口，存成 `docs/screenshot.png`
4. 提交后 README 顶部的 `![截图](docs/screenshot.png)` 就会正常显示

> 建议宽度 1280~1600 px，PNG 格式，控制在 500 KB 以内。
> 截图里不要出现真实的个人文件内容 —— 用 `samples/` 里的样例来截。
