# samples/

放 2 ～ 3 份演示样例，方便评委 / 自己快速试。

建议准备三种，正好覆盖三条处理链路：

| 文件 | 覆盖的能力 |
|---|---|
| `sample.png` / `sample.jpg` | 图片 OCR 路径 |
| `sample.pdf` | PDF 文本层抽取（扫描件则走 OCR） |
| `sample.docx` | Word 正文 + 表格抽取 |

## 注意

- **请勿放入真实的合同、病历、身份证等含个人信息的文件**
- 单文件不超过 20 MB
- 截图或打印出来的样例同样适用（扫描件会走 OCR 分支）

启动项目后，把它们逐个拖进页面即可验证全流程。
